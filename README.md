# Build X - تطبيق الذكاء الاصطناعي المتقدم

تطبيق محادثة ذكي متقدم مع دعم كامل للذكاء الاصطناعي، مبني باستخدام React Native و Expo.

## الميزات

- 🔐 تسجيل الدخول والتسجيل مع حماية كاملة
- 👤 إمكانية دخول الضيف
- 🤖 **دمج حقيقي مع OpenAI و Google AI**
- 💬 واجهة محادثة تفاعلية مع AI
- 📱 دعم كامل للغة العربية (RTL)
- 📎 إرسال الصور والملفات مع تحليل AI
- 🎯 نظام النقاط التفاعلي
- 📢 عرض الإعلانات (جاهز للتفعيل)
- ⚙️ قائمة جانبية تفاعلية مع وظائف حقيقية
- 🔧 **إعدادات API آمنة ومشفرة**
- 💾 حفظ المحادثات محلياً
- 🖼️ **تحليل الصور بالذكاء الاصطناعي**
- 🎨 تصميم مطابق للتطبيق الأصلي

## متطلبات التشغيل

- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn
- Expo CLI
- Android Studio (لبناء APK)
- EAS CLI (لبناء التطبيق)

## 🚀 التشغيل السريع

### 1. تثبيت التبعيات

```bash
npm install
```

### 2. تشغيل التطبيق

```bash
# تشغيل على الويب (مستحسن للتجربة)
npm start -- --web --port 12002

# أو تشغيل عادي
npm start
```

### 3. الوصول للتطبيق
افتح المتصفح على: `http://localhost:12002`

### 4. إعداد API (اختياري)
- احصل على [OpenAI API Key](https://platform.openai.com/api-keys)
- احصل على [Google AI API Key](https://makersuite.google.com/app/apikey)
- أدخل المفاتيح في "إعدادات API" داخل التطبيق

## 📱 البناء للإنتاج

### APK للأندرويد (طريقة سهلة)

```bash
npm run build:apk
```

### AppImage للينكس

```bash
npm run build:appimage
```

### بناء جميع المنصات

```bash
npm run build:all
```

### البناء اليدوي

#### APK للأندرويد:
```bash
# تثبيت EAS CLI
npm install -g @expo/eas-cli

# تسجيل الدخول إلى Expo
eas login

# بناء APK
eas build --platform android --profile preview
```

#### AppImage للينكس:
```bash
# تشغيل الخادم أولاً
npm start -- --web --port 12002

# في terminal آخر
./build-appimage.sh
```

## التخصيص

### تغيير الألوان
عدّل ملف `App.js` في قسم `theme`:

```javascript
const theme = {
  colors: {
    primary: '#2c2c2c',    // اللون الأساسي
    accent: '#f0f0f0',     // اللون الثانوي
    background: '#f5f5f5', // لون الخلفية
    surface: '#ffffff',    // لون السطح
    text: '#000000',       // لون النص
  },
};
```

### إضافة إعلانات جديدة
عدّل ملف `src/components/AdBanner.js` في مصفوفة `ads`.

### تخصيص القائمة الجانبية
عدّل ملف `src/components/SideMenu.js` في مصفوفة `menuItems`.
